🚀 QUICK DEPLOYMENT (Copy-Paste Ready)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Initialize Git (run in terminal)
─────────────────────────────────────────
git init
git add .
git commit -m "Viral Content Studio - Netlify Ready"

Step 2: Push to GitHub (on GitHub.com)
──────────────────────────────────────
1. Create repo: viral-content-studio
2. Get the URL
3. Run:
   git remote add origin https://github.com/YOUR_NAME/viral-content-studio.git
   git branch -M main
   git push -u origin main

Step 3: Connect to Netlify (on Netlify.com)
────────────────────────────────────────────
1. Click "New site from Git"
2. Select your GitHub repo
3. Click "Deploy"
4. Wait 30-60 seconds for deployment

Step 4: Add API Key (in Netlify Dashboard)
───────────────────────────────────────────
1. Site settings → Build & deploy → Environment
2. Click "Edit variables"
3. Add: ANTHROPIC_API_KEY = your_anthropic_api_key
4. Save & trigger redeploy

Step 5: Test (open your live URL)
──────────────────────────────────
1. Select a topic
2. Choose format
3. Click Generate
4. Verify 6 sections load

✨ That's it! Your site is LIVE! 🎉
